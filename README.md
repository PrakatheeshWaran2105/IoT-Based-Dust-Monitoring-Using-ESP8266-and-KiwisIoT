# IoT-Based-Dust-Monitoring-Using-ESP8266-and-KiwisIoT
IoT-Based Dust Monitoring using NodeMCU ESP8266 and SDS011 dust sensor to measure PM2.5 and PM10 particle concentrations and monitor real-time air quality through the KiwisIoT platform.
IoT-Based Dust Monitoring Using ESP8266 and KiwisIoT
About the Project
The IoT-Based Dust Monitoring System is designed to monitor airborne dust particles and measure air pollution levels in the surrounding environment. This project uses a NodeMCU ESP8266 and an SDS011 dust sensor to detect and measure PM2.5 and PM10 particle concentrations.

The ESP8266 collects dust-level readings from the sensor and transmits the data over Wi-Fi to the KiwisIoT platform. Users can monitor real-time dust concentration levels through the KiwisIoT dashboard, making it easier to observe changes in air quality remotely.

This project demonstrates how IoT technology can be used for environmental monitoring, real-time air quality tracking, and dust pollution awareness.
